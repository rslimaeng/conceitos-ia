JSON

A ficha que os sistemas trocam, e por que ela precisa dizer se cada coisa é palavra ou quantidade

Quando um sistema manda informação para outro, ela não vai solta: vai numa ficha com linhas, cada linha com um nome e um valor. O formato dessa ficha é o mesmo no mundo inteiro, e se chama JSON. Você não precisa escrevê-lo do zero. Precisa saber lê-lo, porque é nele que aparece o erro que deixa tudo verde e o resultado errado.

A ficha

Preencha a ficha e veja a máquina escrevê-la

É como a ficha de cadastro de uma recepção: linhas impressas (o nome do campo, que nunca muda) e o que você escreve ao lado (o valor, que muda a cada pessoa). Tem uma linha onde cabe mais de uma coisa, e um quadrinho separado para o endereço. Preencha à esquerda.

O nome do campo fica à esquerda dos dois pontos, o valor à direita. E repare: o nome tem aspas, a idade não.







  Cinco tipos de linha
  
Toda linha da ficha é de um destes cinco tipos

  
Você não precisa decorar os nomes em inglês que a ferramenta mostra. Precisa reconhecê-los quando aparecerem, e saber que o primeiro é palavra e o segundo é quantidade. Clique em cada um.

  

    
    
    
    
    
  

  







  Texto ou número
  
A única regra: eu somaria dois desses?

  
CPF, CEP, telefone e número do pedido são feitos de algarismos, e ninguém soma dois deles: são etiqueta, e etiqueta é palavra. Idade, preço e dias de atraso, somados, significam alguma coisa: são quantidade. O computador não consegue decidir isso sozinho; quem decide é você, pelo uso. Classifique os oito.

  

  







  Quando 10 + 5 dá 105
  
Somar duas palavras cola uma na outra

  
Se um sistema manda o valor como palavra, o próximo passo não faz conta: junta os pedaços. E a comparação "maior que 18" nem começa. Mude os valores e o tipo de cada um.

  

    

      

      

      

      

      

    

    

      A + B
      

      A é maior que 18?
      

    

  

  
A mensagem da comparação é a que as ferramentas mostram de verdade, em inglês: '32' is a string but was expecting a number, ou seja, "esperava uma quantidade e recebeu uma palavra". A saída é converter antes, e a conversão é um passo, não um palpite.







  Ficha dentro da ficha
  
Para chegar num valor, vá de fora para dentro, separando por ponto

  
Um pedido de uma loja tem o cliente, e o cliente tem o endereço. Os itens são uma lista, e cada item é uma ficha. Abra e feche as partes, e clique num valor para ver o caminho até ele. É a mesma lógica de pasta dentro de pasta no computador.

  

    

    

  

  
Na lista, a contagem começa do zero: o primeiro item é itens[0]. E se o quadrinho de dentro não existir num cadastro, o caminho inteiro quebra naquele ponto.







  Tudo chega em lista
  
Três fichas numa lista, e o passo que roda três vezes

  
Uma planilha de 50 linhas chega ao passo seguinte como uma lista de 50 fichas, e o passo roda uma vez para cada uma, sozinho. Mesmo quando aparece "1 item", ele está dentro de uma lista. Troque a visão e rode o passo.

  

    
    
  

  

    

    

      Passo: "Olá, {nome}! Seu cargo é {cargo}."
      

      
      

    

  

  
A tabela arruma para ficar bonito, e nesse arrumar as aspas e o quadrinho de dentro somem. Quando algo der errado, olhe o JSON.







  O erro que não avisa
  
Tudo verde, e o resultado errado

  
Erro que aparece é fácil: a ferramenta avisa e você conserta. O caro é o que passa calado: o e-mail vai para quem não devia, o cliente satisfeito cai na lista dos insatisfeitos. Quase sempre é a regra das aspas aparecendo de outro jeito. Abra cada cartão.

  







  Pedir para a IA
  
Ninguém escreve essa ficha do zero

  
Nem quem programa. O que se faz é descrever em português o que você quer guardar, pedir para a IA montar o formato, e conferir a resposta olhando as aspas. Dois pedidos prontos: um para montar, outro para quando a ferramenta recusar. Veja também como escrever pedidos na página Prompt.

  Para levar
  
Três ideias

  

    
Palavra com aspas, quantidade sem
É a regra inteira. Sim e não viram true e false, também sem aspas.

    
Eu somaria dois desses?
Se a soma não significa nada, é palavra, mesmo escrita com algarismos.

    
A tabela arruma; o JSON conta
Quando o resultado sair errado sem erro nenhum, abra o JSON do passo anterior e olhe as aspas primeiro.

  

  

    
JSON
O formato de ficha que os sistemas usam para trocar informação: nome do campo, dois pontos, valor.

    
Campo (chave)
O nome da linha, à esquerda dos dois pontos. Não muda de uma ficha para outra.

    
Valor
O que foi preenchido, à direita dos dois pontos.

    
Palavra (string)
Texto, sempre entre aspas: nome, cidade, código, telefone.

    
Quantidade (number)
Número de fazer conta, sem aspas: idade, preço, dias.

    
Sim ou não (boolean)
Só dois valores, true e false, sem aspas.

    
Lista (array)
Vários valores numa linha só, entre colchetes. A contagem começa do zero.

    
Ficha dentro (object)
Um quadrinho com linhas próprias, entre chaves. Chega-se nele com ponto: endereco.cidade.

    
Vazio (null)
Nada preenchido. Não é zero, e comparado com um número dá sempre falso.

  

  
Simplificação didática. As fichas, nomes e pedidos são fictícios. O formato JSON tem mais detalhes do que os mostrados aqui; os cinco tipos e a regra das aspas cobrem o que aparece no dia a dia de quem monta automação. Os nomes em inglês entre parênteses são os que as ferramentas costumam mostrar.
