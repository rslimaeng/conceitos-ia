# Conceitos de IA

Biblioteca de conceitos de IA para o trabalho: uma página por conceito, para abrir, mexer e
levar para a rotina. Por Rafael Lima · @iacomrafael.

## 👉 https://rslimaeng.github.io/conceitos-ia/

Os conceitos se organizam em sete famílias. Cada família tem uma página de visão geral e se
abre em páginas menores, uma para cada parte. Cada página é um HTML autossuficiente: funciona
online, no link acima, ou baixada e aberta direto no navegador (baixe a pasta inteira: as imagens da marca ficam em `marca/`).

Este repositório é um espelho. As páginas são editadas em outro lugar e publicadas aqui; não
edite os arquivos direto neste repositório.
